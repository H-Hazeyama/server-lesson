# 練習問題1

このセクション(セクション5)で学んだこと

## コマンドによって様々な操作が出来る。
- ls: ディレクトリ内に存在するディレクトリやファイルを一覧表示する
- pwd: 現在いるディレクトリ＝ワーキングディレクトリを出力する
- cd: ワーキングディレクトリから任意のディレクトリに移動する
- mkdir: ディレクトリの作成
- touch: ファイルの作成
- cp: コピー元、コピー先と記述することで複製する　
-rオプションでディレクトリの複製も可能
- mv: ディレクトリ自体の移動
- rm: ファイルあるいはディレクトリの削除

## ワイルドカード
- ワイルドカード以外の部分がマッチするものを対象として指定することが出来る
- \*: 0文字以上の任意の文字（\*.txtでワーキングディレクトリ内の全てのテキストファイルを指定）
- ?: 任意の一文字（1文字のみの置き換え）

## 実行結果をファイルに書き出す
- >: (実行結果) > (書き込みたいファイル名)　※実行する度上書きする
- >>: (実行結果) >> (書き込みたいファイル名)　※書き込みたいファイルの末尾に実行結果を書き足す

## ファイルの内容を出力する
- cat: 指定したファイル内に書かれた内容をコマンドプロンプト上に表示する

## エディタ
- vim: コマンドプロンプト上にて、指定したファイル内に書き込むエディタを起動する
- i: エディタ内で書き込むインサートモードに切り替え
- esc: エディタの保存、移動や検索などを行うノーマルモードに切り替え
- エディタ内で自分が現在どちらのモードで操作しているか把握する
- 入力を終えた後はノーマルモードに戻り「:wq」を実行して編集内容を保存することが重要
